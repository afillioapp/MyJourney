## 6. Can the gate be checked as written?

Only partly. "With no questions left" can be tested by doing the developer read above. But nothing says which questions count: product questions only, or implementation questions too. Proposed checkable version, for the user to adopt or reject:

> Phase 1 passes when, for every table, column, constraint, RLS policy, function and fixture row that P1 §2–§3 implies:
> 1. its behaviour is fixed by P1, FS §20 or a DN provisional default, with no unlisted product question (U-type = 0);
> 2. every implementation question raised by the read has a written answer from its owner agent, recorded in P1 or an annex (O-type = 0);
> 3. every §2.5 check has a rubric how-to-check that can be run with the time controls P1 defines;
> 4. every count and example in P1 §3 can be derived from its own fixture tables, and every restatement of a decision dated in the phase matches (L-002).

Under this version the result today is: (1) 4 open, (2) 6 open, (3) fails on O1, (4) fails on CF-1 and CF-2.
